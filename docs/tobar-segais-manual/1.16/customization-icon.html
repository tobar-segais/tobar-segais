Icon customization

There are a number of icons which can be replaced quite simply.

The following instructions assume you are building your Tobar Segais web application using the technique described in Chapter 2.

  • Header logo - src/main/webapp/img/header-logo.png

  • Favicon - src/main/webapp/img/favicon.ico

  • Apple Touch Icons - src/main/webapp/img/apple-touch-icon.png, src/main/webapp/img/apple-touch-icon-72x72.png, src/main/webapp/img/apple-touch-icon-114x114.png and src/main/webapp/img/apple-touch-icon-144x144.png,
